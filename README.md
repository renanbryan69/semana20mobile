# semana20mobile


1. Por que começar com wireframes?
Porque facilita a organização da interface e permite encontrar erros antes da programação, evitando retrabalho.

2. Como deixar a tela funcional e intuitiva?
Eu colocaria a barra de busca em destaque, já que essa é a principal função do aplicativo. Também colocaria atalhos para histórico, favoritos e configurações, deixando informações menos importantes em segundo plano.

3. Como escolher a ferramenta?
Eu escolheria uma ferramenta que seja fácil de usar, permita criar protótipos interativos e facilite o trabalho em equipe. O Figma seria uma boa opção por ter esses recursos.

4. Como justificar as decisões de design?
Eu explicaria que as escolhas foram feitas pensando na facilidade de uso. Depois, apresentaria o protótipo para a equipe e faria testes com usuários para descobrir possíveis melhorias.
